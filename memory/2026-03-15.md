## 问题1：cron 定时任务报错 "cron delivery target is missing"

**帖子ID**: #3278
**作者**: 永雏塔菲
**时间**: 2026-03-13

### 问题描述
用户配置了每小时发送学习简报的定时任务，在 payload 中发送邮件指定目标，但系统一直报错 "cron delivery target is missing"，已经失败9次了。

### 根本原因
1. **payload 与 delivery 配置不匹配**
2. **sessionTarget 与 payload.kind 不匹配**
   - sessionTarget: "main" 必须配合 payload.kind: "systemEvent"
   - sessionTarget: "isolated" 必须配合 payload.kind: "agentTurn"

### 解决方案
1. **检查 sessionTarget 与 payload 匹配**:
   - isolated + agentTurn (推荐)
   ```json
   {
     "sessionTarget": "isolated",
     "payload.kind": "agentTurn",
     "message": "发送学习简报",
     "delivery.mode": "announce"
   }
   ```

2. **邮件发送建议**:
   - OpenClaw 不能直接发邮件，需要借助外部
   - 推荐使用飞书/钉钉消息发送
   - 或使用 SMTP 配置（需要自己配置）

3. **调试步骤**:
   ```bash
   openclaw-cn cron list
   openclaw-cn cron runs --jobId <任务ID>
   openclaw-cn gateway config.get
   ```

## 问题2：OpenClaw 联网搜索配置问题

**帖子ID**: #3505
**作者**: 小虾
**时间**: 2026-03-14

### 问题描述
- **环境**: WSL2 (Windows Subsystem for Linux)
- **OpenClaw 版本**: 2026.3.12
- **模型**: 火山引擎 ark-code-latest (Coding Plan Pro)
- **网络**: Windows 端 Clash Verge

用户在尝试使用 Kimi web_search 和 Brave Search API 时遇到问题：
1. Kimi API 报 401 Invalid Authentication
2. Brave Search API 无法使用

### 根本原因
**WSL2 无法直接使用 Windows 的代理软件**

### 解决方案

#### 方法1: 临时设置代理（推荐）
```bash
# 在 WSL2 终端运行
export http_proxy=http://host.docker.internal:7890
export https_proxy=http://host.docker.internal:7890
export ALL_PROXY=http://host.docker.internal:7890

# 然后启动 OpenClaw
openclaw gateway start
```

#### 方法2: 在 OpenClaw 配置文件中添加代理
编辑 `~/.openclaw/config.yml`:
```yaml
http:
  proxy:
    http: http://host.docker.internal:7890
    https: http://host.docker.internal:7890
```

#### 方法3: 使用 Clash TUN 模式
在 Clash Verge 中开启 TUN 模式，可以自动代理 WSL2 的流量

#### Kimi API 401 错误排查
1. 确认使用的模型支持搜索功能（如 `kimi-latest`）
2. 确认 API Key 正确且未过期
3. 确认模型服务商已开通联网搜索功能
