**日期：2026-03-16**

## 核心理解

OpenClaw 采用"轻内核、重插件"的设计架构。默认状态就像刚刷完机的手机，必须安装 Skills（技能）才能发挥真正的生产力。

## 4个必装 Skills

### 1. Find Skills（技能导航仪）
- **作用**：自然语言查找推荐技能，解决"该装什么"的困惑
- **安装**：`npx clawhub@latest install find-skills`
- **用法**：说"帮我找一个能批量处理 Excel 的技能"，自动推荐安装命令

### 2. Tavily Search（精准搜索）
- **作用**：专为 AI 设计的搜索引擎，获取实时精准信息（解决模型知识截止日期问题）
- **安装**：`npx clawhub@latest install tavily-search`
- **配置**：建议设置 language=zh-CN
- **用法**：
  - `--deep` 深度搜索模式
  - `--news` 新闻专题搜索

### 3. Multi Search Engine（全网聚合）
- **作用**：集成17个搜索引擎（百度/谷歌/必应等），无需 API Key
- **安装**：`npx clawhub@latest install multi-search-engine`
- **优势场景**：
  - 多来源对比验证
  - 隐私保护（DuckDuckGo）
  - 知识计算（WolframAlpha 数学）

### 4. Office-Automation（办公自动化）
- **作用**：生成周报、处理Excel、发送邮件、管理日程
- **安装**：`npx clawhub@latest install office-automation`
- **注意**：需配置 SMTP（授权码非登录密码），配置后需重启服务

## 技能组合拳

### 信息调研 → 报告生成
```
Multi Search Engine（广度搜集）→ Tavily Search（深度挖掘）→ Office-Automation（输出PDF/邮件）
```

### 能力扩展 → 执行任务
```
Find Skills（找技能）→ Office-Automation（执行）
```

## 新手避坑（FAQ）

| 问题 | 解决方案 |
|------|----------|
| API-Key invalid | 核对密钥、检查是否启用、选对模型提供商 |
| 安装超时 | 配置国内镜像源 `openclaw config set plugins.registry` |
| 端口占用 | `lsof -i:18789` 找PID，`kill -9 <PID>` |
| 技能not ready | 启用+安装依赖+重启服务 |
| 邮件发送失败 | 用授权码非密码，检查防火墙端口 |

## 管理命令汇总

```bash
# 查看技能状态
openclaw skills list --status ready

# 安装/卸载
npx clawhub@latest install <skill>
openclaw skills uninstall <skill>

# 启用/禁用
openclaw skills enable/disable <skill>

# 更新
npx skills check
npx skills update all

# 重启服务
openclaw gateway restart
```
