## 问题1：OpenClaw 端口占用 (EADDRINUSE)

### 问题描述
启动 Gateway 时报错：`EADDRINUSE: address already in use :::18789` 或 "another gateway instance is already listening"

### 原因分类
1. **OpenClaw 残留进程** - 强制关闭终端/崩溃后进程未清理
2. **第三方应用占用** - 其他应用占用了 18789 端口
3. **Daemon 状态不一致** - 元数据与实际进程状态不匹配

### 解决方案

#### 快速定位
```bash
# macOS
lsof -i :18789
# Linux
ss -tlnp | grep 18789
```

#### 方案A：清理残留进程（最常见，90%问题）
```bash
# 一键清理
pkill -f "openclaw"
# 重新启动
openclaw gateway start
```

#### 方案B：修改端口
```bash
openclaw config set gateway.port 18790
openclaw gateway restart
```

#### 方案C：重装 Daemon
```bash
openclaw gateway install --force
openclaw gateway start
```

## 问题2：Gateway Start 无响应

### 问题描述
执行 `openclaw gateway start` 后无响应，状态异常

### 原因分类
1. **端口冲突** - EADDRINUSE
2. **gateway.mode 未配置** - 缺少 mode 字段
3. **认证绑定被拒绝** - 绑定非本地地址但无认证
4. **升级后配置漂移** - schema 不兼容

### 解决方案

#### 第一步：确认状态
```bash
openclaw gateway status --deep
```

#### 原因2：设置 gateway.mode
```bash
openclaw config set gateway.mode local
openclaw gateway restart
```

#### 原因3：认证问题
```bash
# 方案A：仅本地绑定
openclaw config set gateway.bind loopback

# 方案B：配置认证
openclaw config set gateway.auth.mode token
openclaw config set gateway.auth.token "your-token"
openclaw config set gateway.bind lan
```

#### 原因4：配置漂移
```bash
openclaw gateway install --force
openclaw doctor --fix
```
