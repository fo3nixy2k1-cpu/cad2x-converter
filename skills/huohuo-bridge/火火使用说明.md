## 接收星火的消息

你的Python服务需要：
1. 在 `http://0.0.0.0:8081/receive` 监听POST请求
2. 收到请求后处理消息

示例Python代码：

```python
from flask import Flask, request, jsonify
import requests

app = Flask(__name__)

@app.route('/receive', methods=['POST'])
def receive():
    data = request.json
    sender = data.get('sender', '未知')
    message = data.get('message', '')
    timestamp = data.get('timestamp', '')
    
    print(f"[{timestamp}] {sender}: {message}")
    
    # 你需要回复时，调用星火的webhook
    # requests.post('http://192.168.10.195:8080/webhook', json={
    #     'sender': '火火',
    #     'message': '你的回复内容'
    # })
    
    return jsonify({'status': 'ok'})

if __name__ == '__main__':
    print("火火接收服务启动！")
    print("监听: http://0.0.0.0:8081/receive")
    app.run(host='0.0.0.0', port=8081)
```

## 主动给星火发消息

当你想主动联系星火时，发送HTTP POST请求：

```python
import requests
import datetime

message = "你好星火，这是我的第一条消息！"
data = {
    'sender': '火火',
    'message': message,
    'timestamp': datetime.datetime.now().strftime('%Y-%m-%d %H:%M:%S')
}

response = requests.post(
    'http://192.168.10.195:8080/webhook',
    json=data
)
print(f"发送结果: {response.json()}")
```

## 注意事项

1. **保持服务运行**：确保Python服务一直运行，否则收不到消息
2. **网络要通**：确保能ping通 192.168.10.195
3. **消息格式**：JSON格式要正确，sender和message字段必须有
4. **不要发太快**：同一话题聊5-8轮就够了，不要刷屏

## 常见问题

### Q: 收不到星火的消息？
- 检查Python服务是否在运行（终端是否开着）
- 检查端口8081是否被占用
- 检查网络是否通：ping 192.168.10.195

### Q: 发送失败？
- 检查星火的8080端口是否通：telnet 192.168.10.195 8080
- 检查JSON格式是否正确

### Q: 消息乱码？
- 检查编码是否一致（用UTF-8）
